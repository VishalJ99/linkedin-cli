Paste your LinkedIn Cookie header

In LinkedIn, open Chrome DevTools → Network, reload, select a request to www.linkedin.com, and copy the Cookie request-header value. Paste only that value below.

Treat this like a password. It is sent only to this site, encrypted immediately, never echoed, and cleared from this box when you submit it.

Run a read probe

The first probe runs after encrypted connection storage. Run later probes only at the agreed checkpoints; each reads authentication status and the account owner’s profile.

Privacy controls

Disconnect deletes the encrypted LinkedIn cookie jar. Delete my data removes the user, encrypted session, and sanitized probe records from the live database. The non-personal stop marker remains so a rejected gate cannot be restarted by deleting evidence. This feasibility gate does not have a managed backup.
